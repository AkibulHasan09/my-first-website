## 📌 Project Overview

**DevConf 2026** is a modern and responsive conference website designed for the premier developer conference of 2026.

The event brings together **4,000+ engineers, founders, and builders** for three days of cutting-edge talks, hands-on workshops, networking opportunities, and meaningful connections.

The website provides visitors with essential information about the conference while presenting the content through a clean, modern, and user-friendly interface.

## ✨ Features

* 🎤 **Conference Talks** — Explore cutting-edge talks from industry experts.
* 🛠️ **Hands-on Workshops** — Discover practical workshops and learning opportunities.
* 🚀 **Hackathon Details** — Information about the DevConf 2026 hackathon.
* 🤝 **Community & Networking** — Connect with engineers, founders, and builders.
* 💼 **Developer Job Board** — Discover relevant career opportunities.
* 📍 **Venue Information** — Find conference venue and event details.
* ❓ **FAQ Section** — Get answers to frequently asked questions.
* 📩 **Newsletter Signup** — Stay updated with DevConf announcements.
* 📸 **Past Highlights** — Explore memorable moments from previous events.
* 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
* 🎨 **Modern Card-Based UI** — Clean sections with visually engaging cards and typography.

## 💻 Run the Project Locally

Follow these steps to run DevConf 2026 on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/AkibulHasan09/dev-conf-2026.git
```

### 2. Navigate to the Project Directory

```bash
cd dev-conf-2026
```

### 3. Open the Project

Simply open the `index.html` file in your browser.

Or, if you are using **VS Code**, you can use the **Live Server** extension.

```text
Right Click → Open with Live Server
```

The website should now be running locally.
